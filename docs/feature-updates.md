# 功能更新文档

本文档记录了系统的最新功能更新和改进。

## 最新更新 (2026-01-22)

### 1. 任务完成权限管理

#### 功能说明
- 新增 `task:complete` 权限，允许司机和维修员确认完成任务
- 司机和维修员角色已自动分配此权限
- 管理员和调度员默认拥有此权限

#### 权限配置
- **权限代码**: `task:complete`
- **权限名称**: 完成任务
- **权限类型**: 按钮权限
- **已分配角色**: DRIVER（司机）、MAINTENANCE（维修员）

#### 使用方式
1. 在调度中心页面，司机和维修员可以看到"完成任务"按钮
2. 对于状态为"已分配"（2）或"执行中"（3）的任务，可以点击完成
3. 完成任务后，系统会自动更新车辆状态和任务状态

### 2. 权限实时刷新功能

#### 功能说明
- 支持权限更新后实时刷新，无需重新登录
- 在个人资料页面可以查看当前权限列表
- 提供"刷新权限"按钮，一键获取最新权限

#### 使用方式
1. **自动提示刷新**：
   - 管理员在系统设置中更新角色权限后
   - 如果当前用户属于该角色，系统会提示是否立即刷新权限

2. **手动刷新权限**：
   - 进入"个人资料"页面
   - 在"权限信息"卡片中点击"刷新权限"按钮
   - 系统会从服务器获取最新权限并更新

#### API接口
- **接口地址**: `GET /api/users/me`
- **返回内容**: 用户信息（包含角色和权限列表）
- **权限要求**: 需要用户认证

### 3. 车辆状态自动更新

#### 功能说明
- 根据任务状态自动更新车辆状态
- 维护调度任务完成后，车辆状态自动更新为"正常"

#### 更新规则
1. **任务分配时**：
   - 维护调度任务：车辆状态更新为"维修中"（2）
   - 普通调度任务：车辆状态保持"正常"（1）

2. **任务完成时**：
   - 维护调度任务：车辆状态更新为"正常"（1）
   - 普通调度任务：车辆状态保持"正常"（1）

3. **报告提交时**：
   - 故障类型报告：车辆状态更新为"故障"（3）

### 4. 任务编号生成优化

#### 功能说明
- 改进任务编号生成算法，避免并发冲突
- 使用时间戳+随机数生成唯一编号
- 自动检测并重试，确保编号唯一性

#### 编号格式
- 格式：`TASK + 日期(yyyyMMdd) + 序号(0001-9999)`
- 示例：`TASK202601220001`

#### 技术实现
- 使用时间戳毫秒数后4位 + 随机数（0-99）
- 循环检查确保编号唯一（最多尝试10次）
- 支持高并发场景下的唯一性保证

### 5. 邮件测试功能

#### 功能说明
- 在系统设置页面可以测试邮件发送功能
- 支持向已配置邮箱的用户发送测试邮件
- 测试邮件包含系统信息和配置验证说明

#### 使用方式
1. 进入"系统设置" -> "邮件配置"
2. 在"已填写邮箱的用户列表"中，点击"测试发送"按钮
3. 确认后，系统会向该用户的邮箱发送测试邮件

#### API接口
- **接口地址**: `POST /api/email/test`
- **请求参数**:
  ```json
  {
    "email": "user@example.com",
    "subject": "测试邮件 - 机场车辆监控与调度系统"
  }
  ```
- **权限要求**: 需要用户认证

### 6. 邮件通知类型说明优化

#### 功能说明
- 邮件通知类型说明区域支持滚动查看
- 最大高度500px，超出部分可滚动
- 自定义滚动条样式，提升用户体验

#### UI改进
- 添加滚动容器，固定高度
- 美化滚动条样式
- 确保所有内容都可以查看

### 7. 告警与任务关联

#### 功能说明
- 告警可以关联车辆报告（reportId）
- 告警可以关联调度任务（taskId）
- 支持从告警创建维护任务

#### 使用场景
1. **从报告创建告警**：
   - 司机或维修员提交故障报告时，系统自动创建告警
   - 告警自动关联报告ID

2. **从告警创建任务**：
   - 管理员可以在告警详情页面创建维护任务
   - 任务创建后，告警自动关联任务ID

3. **任务完成更新告警**：
   - 完成任务后，关联的告警状态自动更新

## 数据库更新

### 新增权限
```sql
INSERT INTO `sys_permission` (`permission_name`, `permission_code`, `permission_type`, `description`, `status`) 
VALUES ('完成任务', 'task:complete', 'button', '确认完成任务', 1);
```

### 角色权限分配
```sql
-- 司机角色
INSERT INTO `sys_role_permission` (`role_id`, `permission_id`)
SELECT 3, id FROM `sys_permission` WHERE `permission_code` = 'task:complete';

-- 维修员角色
INSERT INTO `sys_role_permission` (`role_id`, `permission_id`)
SELECT 4, id FROM `sys_permission` WHERE `permission_code` = 'task:complete';
```

### 告警表字段
- `report_id`: 关联的车辆报告ID
- `task_id`: 关联的调度任务ID

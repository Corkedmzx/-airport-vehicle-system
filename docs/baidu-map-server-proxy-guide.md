# 百度地图服务端代理配置指南

## 概述

由于百度地图的Referer白名单不支持端口格式（如 `localhost:3000`），我们采用**服务端代理**的方式来解决这个问题。

### 优势

1. **安全性更高**：AK不会暴露在前端代码中
2. **支持IP白名单**：后端可以使用IP白名单（支持端口格式）
3. **灵活配置**：可以统一管理API调用和限流
4. **避免Referer限制**：不需要配置Referer白名单

## 架构设计

```
前端 (localhost:3000)
    ↓ HTTP请求
后端API (/api/baidu-map/api-script)
    ↓ 返回包含AK的API URL
前端动态加载百度地图API脚本
    ↓ 使用百度地图API
前端地图显示
```

## 配置步骤

### 1. 申请百度地图AK

1. 访问：https://lbsyun.baidu.com/apiconsole/key
2. 创建应用，选择"服务端"类型
3. 配置IP白名单（**只支持IP地址，不支持端口**）：
   
   **精确配置：**
   ```
   127.0.0.1,192.168.172.170,192.168.189.1,192.168.234.1,172.23.64.1
   ```
   
   **或者使用CIDR网段（推荐）：**
   ```
   127.0.0.1,192.168.0.0/16,172.16.0.0/12
   ```
   
   **说明：**
   - IP白名单**不支持端口格式**（如 `localhost:3000` 或 `127.0.0.1:3000`）
   - 只支持IP地址（如 `127.0.0.1`）或CIDR网段（如 `192.168.0.0/16`）
   - 多个IP用英文半角逗号分隔
   - 如果不想限制，可以设置为 `0.0.0.0/0`（**仅开发环境使用**）
   
4. 复制生成的AK

### 2. 配置后端环境变量

在 `backend/.env` 文件中添加：

```bash
# 百度地图AK（服务端类型）
BAIDU_MAP_AK=your-baidu-map-ak-here
```

**说明：**
- 系统会自动从 `.env` 文件加载环境变量
- 启动后端服务时，会自动读取 `.env` 文件中的配置
- 如果 `.env` 文件不存在，会使用 `application.yml` 中的默认值
- 环境变量优先级：系统环境变量 > `.env` 文件 > `application.yml` 默认值

### 3. 更新application.yml（可选）

如果不想使用环境变量，可以在 `backend/src/main/resources/application.yml` 中配置：

```yaml
baidu:
  map:
    ak: ${BAIDU_MAP_AK:}  # 从环境变量读取
    api:
      base-url: https://api.map.baidu.com
```

### 4. 启动服务

```bash
# 启动后端
cd backend
mvn spring-boot:run

# 启动前端
cd frontend
npm run dev
```

## IP白名单配置

### 重要说明

**IP白名单只支持IP地址，不支持端口格式！**

- 支持：`127.0.0.1`、`192.168.1.1`、`192.168.0.0/16`
- 不支持：`localhost:3000`、`127.0.0.1:3000`、`192.168.1.1:8080`

### 开发环境配置

在百度地图控制台，选择"服务端"应用类型，配置IP白名单：

**方式1：精确IP配置**
```
127.0.0.1,192.168.172.170,192.168.189.1,192.168.234.1,172.23.64.1
```

**方式2：使用CIDR网段（推荐，更灵活）**
```
127.0.0.1,192.168.0.0/16,172.16.0.0/12
```

**说明：**
- `127.0.0.1` - 本地回环地址
- `192.168.0.0/16` - 覆盖所有192.168.x.x网段的IP（包括192.168.172.170、192.168.189.1等）
- `172.16.0.0/12` - 覆盖所有172.16.0.0到172.31.255.255的IP（包括172.23.64.1等）

**方式3：不限制（仅开发环境，不推荐）**
```
0.0.0.0/0
```

**警告**：`0.0.0.0/0` 表示允许所有IP访问，存在安全风险，仅建议在开发调试阶段使用。

### 生产环境配置

如果部署到生产服务器，添加服务器IP：

```
127.0.0.1,192.168.0.0/16,172.16.0.0/12,您的服务器IP
```

或者使用精确配置：
```
127.0.0.1,192.168.172.170,192.168.189.1,192.168.234.1,172.23.64.1,您的服务器IP
```

## API接口说明

### 1. 获取百度地图API脚本URL

**接口：** `GET /api/baidu-map/api-script`

**响应：**
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "apiUrl": "https://api.map.baidu.com/api?v=3.0&ak=您的AK",
    "ak": "您的AK"
  }
}
```

### 2. 代理调用百度地图API（可选）

**接口：** `GET /api/baidu-map/proxy/**`

用于代理调用其他百度地图API接口，自动添加AK参数。

## 前端使用

前端代码已经自动适配，无需修改。地图初始化时会：

1. 调用 `/api/baidu-map/api-script` 获取API URL
2. 动态加载百度地图API脚本
3. 初始化地图

## 故障排查

### 问题1：提示"百度地图AK未配置"

**解决方法：**
1. 检查 `backend/.env` 文件中是否配置了 `BAIDU_MAP_AK`
2. 检查环境变量是否正确加载
3. 重启后端服务

### 问题2：提示"key未授权"

**解决方法：**
1. 检查百度地图控制台中的应用类型是否为"服务端"
2. 检查IP白名单是否包含当前访问的IP和端口
3. 等待几分钟后重试（配置可能需要时间生效）

### 问题3：地图无法加载

**解决方法：**
1. 检查后端服务是否正常运行
2. 检查浏览器控制台是否有错误信息
3. 检查网络连接，确认可以访问百度地图API

### 问题4：IP白名单配置错误

**解决方法：**
1. 确认应用类型为"服务端"（不是"浏览器端"）
2. **检查IP格式：只支持IP地址，不支持端口格式**
   - 正确：`127.0.0.1`、`192.168.0.0/16`
   - 错误：`localhost:3000`、`127.0.0.1:3000`
3. 使用CIDR网段配置可以避免IP变化的问题
4. 多个IP用英文半角逗号分隔

## 安全建议

1. **不要在前端代码中硬编码AK**
2. **使用环境变量管理AK**
3. **定期检查API调用量，发现异常及时处理**
4. **生产环境使用精确的IP白名单**
5. **不要将 `.env` 文件提交到Git仓库**

## 对比：Referer白名单 vs IP白名单

| 特性 | Referer白名单 | IP白名单 |
|------|--------------|----------|
| 应用类型 | 浏览器端 | 服务端 |
| 支持格式 | HTTP/HTTPS网址（如 `localhost`、`*.example.com`） | IP地址或CIDR网段（如 `127.0.0.1`、`192.168.0.0/16`） |
| 支持端口 | 不支持（只能配置域名） | 不支持（只能配置IP） |
| 安全性 | 中等（AK暴露在前端） | 高（AK在后端） |
| 配置复杂度 | 高（需要配置域名） | 低（只需配置IP） |
| 推荐场景 | 前端直接调用 | 后端代理调用 |
